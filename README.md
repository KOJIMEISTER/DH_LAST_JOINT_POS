# DH_LAST_JOINT_POS

![Preview](https://github.com/KOJIMEISTER/DH_LAST_JOINT_POS/blob/main/images/show.png)

## Описание

**DH_LAST_JOINT_POS** — это настольное приложение, разработанное на C++ с использованием Qt и QML, предназначенное для расчёта координат последнего соединения манипулятора с помощью матрицы Денавита-Хартенберга (Denavit–Hartenberg Parameters). Приложение позволяет загружать конфигурационные файлы, настраивать параметры углов поворота (Theta) и отображать результаты расчёта координат x, y, z в режиме реального времени.

## Возможности

- **Расчёт координат последнего соединения** манипулятора на основе введённых параметров Денавита-Хартенберга.
- **Загрузка конфигурационных файлов** в формате JSON для быстрой настройки параметров.
- **Интерактивный интерфейс** с возможностью регулировки углов поворота (Theta) посредством слайдеров.
- **Многопоточность** для обеспечения плавной работы приложения без задержек.
- **Поддержка стилей Material Design** для современного и эстетичного интерфейса.

## Установка

### Требования

- **C++20** компилятор
- **CMake** версии 3.14 или выше
- **Qt 6** с модулями: Core, Quick, QuickControls2, Gui

### Сборка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/KOJIMEISTER/dh_last_joint_pos.git
   cd dh_last_joint_pos
   ```

2. **Создайте директорию для сборки и перейдите в неё:**
   ```bash
   mkdir build
   cd build
   ```

3. **Выполните CMake для генерации файлов проекта:**
   ```bash
   cmake ..
   ```

4. **Соберите проект:**
   ```bash
   cmake --build .
   ```

5. **Запустите приложение:**
   ```bash
   ./dh_last_joint_pos
   ```

## Использование

1. **Запустите приложение.**
2. **Загрузите конфигурационный файл:**
   - Нажмите на кнопку в левом нижнем углу приложения.
   - В открывшемся окне выберите файл `config.json`.
3. **Настройте параметры Theta:**
   - Используйте слайдеры для регулировки углов поворота каждого соединения.
   - Координаты x, y, z будут обновляться автоматически в правой панели.

## Конфигурация

Файл `config.json` содержит параметры DH-параметров манипулятора. Пример содержания:

```json
[
  {
    "Theta": 15.0,
    "A": 0,
    "D": 0.213,
    "Alpha": 1.570796327
  },
  {
    "Theta": -50.0,
    "A": -0.8,
    "D": 0.193,
    "Alpha": 0
  },
  // ... другие соединения
]
```

- **Theta:** Угол поворота в градусах.
- **A:** Длина звена.
- **D:** Сдвиг по оси предыдущего звена.
- **Alpha:** Угол между осями звеньев.

# Дополнительная информация

Проект использует многопоточность с использованием `QThread` для выполнения тяжёлых вычислений в фоновом режиме, обеспечивая отзывчивость пользовательского интерфейса. Интерфейс был разработан с помощью QML, что позволяет легко настраивать и изменять внешний вид приложения.

### Основные компоненты:

- **backend.h/cpp:** Управление данными и взаимодействие между QML и C++.
- **DH.h/cpp:** Реализация алгоритма Денавита-Хартенберга для расчёта позиций.
- **dhworker.h/cpp:** Обработка очереди задач для вычислений в отдельном потоке.
- **matrix4d.h/cpp:** Работа с 4x4 матрицами для преобразований.
- **main.cpp:** Инициализация приложения и подключение компонентов.
- **main.qml:** Определение пользовательского интерфейса.
- **CMakeLists.txt:** Сборка проекта с использованием CMake.
